# Deni Apps

The current website is the standalone static homepage in [`static-site/`](static-site/README.md), ready for Cloudflare Pages.

- **Active site:** `static-site/public/` — HTML, CSS, logo, and contact information.
- **Deployment:** see [`static-site/README.md`](static-site/README.md) for Cloudflare Git integration and manual deployment.
- **Archived frontend:** `next/` — preserved in its original location for reference.
- **Archived backend:** `feathers/` — preserved in its original location for reference.
- **Legacy documentation:** [`ARCHIVE.md`](ARCHIVE.md).

The legacy directories are archived in place to preserve their files and relative paths. They are not part of the new deployment, and the static site does not use their services, dependencies, or database. Existing hosting must be retired separately after switching the domain to Cloudflare.
